# johncbogil.github.io

Preview the site from the repository root with `python3 -m http.server 8000`,
then open `http://localhost:8000/`.

The homepage's social sharing image is `assets/social-preview.png` (1200 × 630).
Its editable HTML artwork is `assets/social-preview.html`; after editing it,
export a screenshot at 1200 × 630 with a device scale factor of 1 to replace the
PNG. The image is static, so GitHub Pages needs no build step.
